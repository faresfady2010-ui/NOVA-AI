NOVA is an experimental language model project. These short examples exist to exercise the data pipeline; they are not enough to teach general language ability.

A language model learns statistical patterns by predicting the next token in a sequence. NOVA represents text as UTF-8 bytes, so each byte is a token. This representation can encode any Unicode text, including English and Arabic, but it is less efficient than a subword vocabulary.
