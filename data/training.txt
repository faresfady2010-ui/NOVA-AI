NOVA is an experimental language model project. These short examples exercise a training pipeline; they are not enough to teach general language ability.

A language model learns statistical patterns by predicting the next token in a sequence. NOVA represents text as UTF-8 bytes, so each byte is one token. This can encode English, Arabic, punctuation, and other Unicode text, though byte tokens use context inefficiently.
